# T19 Taint egress

- Stimulus: A member sends a note derived from external-untrusted content to a third-party destination
- Required observation: Egress is blocked unless disclosure policy allows that destination; receipt names the source chain.
- Gates stage: 2b
- Profiles: protected required; cooperative may report unenforced.
- Status: not implemented.
