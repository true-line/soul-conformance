# Stage 1 task-authority flow

One runner exercises T04, T05 and T20 against the pinned real HQ. It admits a
lead and specialist from the shared `hello.first-start` fixture, binds both to
an independent deterministic broker transport, offers one owner task and
records one peer offer.

The run passes only when the peer remains peer data with no grant or directive,
four deliveries over two bound connections produce one transition and a stable
receipt, and the specialist produces a proposal before the lead makes the sole
final commitment. The emitted report names the exact HQ and contract archives,
fresh platform main, host, cooperative profile, exercised conformance transport
and separately labeled fixture-requested adapter. It makes no protected-host
or full entry-point claim; those boundaries stay explicit in the report.
